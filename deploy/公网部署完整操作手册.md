## 二、部署架构（一张图看懂）

```
用户浏览器
   │  http://139.199.12.160
   ▼
Caddy 反向代理 (80/443，自动 HTTPS，公网唯一入口)
   │
   ▼
Nginx (前端 Vue3 静态页 + /api 反代)
   │
   ▼
FastAPI 网关 gateway:8000（JWT 鉴权 + 限流 + 反爬）
   ├── auth-service:8001     （登录/注册/用户）
   ├── pmc-service:8002      （102 个业务模块 CRUD + 导出）
   ├── warning-service:8003  （预警中心）
   └── report-service:8004   （数据报表）
   │
   ├── PostgreSQL 16  （数据持久化）
   └── RabbitMQ 3.13  （服务间事件通信：数据变更→预警广播）
```

**安全设计**：只有 80/443 对外；数据库、RabbitMQ、各服务端口全部不暴露公网；接口带 JWT 鉴权 + 限流 + 反爬 UA 拦截。

## 三、首次部署步骤（全新服务器）

### 第 1 步：买服务器

1. 腾讯云控制台 → **轻量应用服务器** → 新建
2. 配置选：**2核4G / 60G SSD / 500G流量**
3. 地域选离你最近的（广州/深圳）
4. **镜像选「系统镜像 → Ubuntu 22.04 LTS」**（⚠️ 别选宝塔Windows版，Windows 跑不了 Linux 容器）
5. 设置 root 密码并牢记

### 第 2 步：放行防火墙（关键！）

控制台 → 实例详情 → **「防火墙」** tab → 添加 3 条规则：

| 应用类型 | 协议 | 端口 | 来源 |
|---|---|---|---|
| Linux登录(22) | TCP | 22 | 0.0.0.0/0 |
| HTTP(80) | TCP | 80 | 0.0.0.0/0 |
| HTTPS(443) | TCP | 443 | 0.0.0.0/0 |

> 不开放这三条，外部永远连不上。80/443 用于网站，22 用于 SSH 管理。

### 第 3 步：SSH 连上服务器

Windows PowerShell 自带 SSH（`C:\Windows\System32\OpenSSH\ssh.exe`）：

```powershell
ssh root@139.199.12.160
# 输入第 1 步设置的 root 密码
```

### 第 4 步：安装 Docker（含国内镜像加速）

```bash
# 1) 装 Docker（走腾讯云内网源，国内快）
apt-get update
apt-get install -y ca-certificates curl gnupg
install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://mirrors.cloud.tencent.com/docker-ce/linux/ubuntu/gpg | gpg --dearmor -o /etc/apt/keyrings/docker.gpg
chmod a+r /etc/apt/keyrings/docker.gpg
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/docker.gpg] https://mirrors.cloud.tencent.com/docker-ce/linux/ubuntu jammy stable" > /etc/apt/sources.list.d/docker.list
apt-get update
apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
systemctl enable --now docker
docker --version   # 确认安装成功

# 2) 配置国内镜像加速（Docker Hub 在国内被墙，必配！）
mkdir -p /etc/docker
cat > /etc/docker/daemon.json <<'EOF'
{
  "registry-mirrors": ["https://mirror.ccs.tencentyun.com", "https://docker.m.daocloud.io"]
}
EOF
systemctl restart docker
```

### 第 5 步：拉取项目代码

```bash
cd /opt
git clone --depth 1 https://github.com/tubuqianqiulu/pmc-manager.git
```

### 第 6 步：构建镜像 + 配置

> 说明：应用镜像在 ghcr.io 上默认是私有包，匿名拉不了；而且服务器是 2核4G，直接本地构建最稳（约 10 分钟）。

```bash
cd /opt/pmc-manager

# 给构建加国内源（加速 pip/npm）
sed -i 's#pip install --no-cache-dir -r requirements.txt#pip install --no-cache-dir -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple#' backend/Dockerfile
sed -i 's#RUN npm ci || npm install#RUN npm config set registry https://registry.npmmirror.com \&\& npm ci || npm install#' frontend/Dockerfile

# 构建后端（所有微服务共用一个镜像，用不同 command 区分入口）
docker build -t pmc-backend:local ./backend
for svc in auth-service pmc-service warning-service report-service gateway; do
  docker tag pmc-backend:local ghcr.io/tubuqianqiulu/pmc-manager-$svc:latest
done
# 构建前端
docker build -t ghcr.io/tubuqianqiulu/pmc-manager-frontend:latest ./frontend
```

### 第 7 步：生成生产配置并启动

```bash
cd /opt/pmc-manager/deploy

# 生成强随机密钥
JWT=$(openssl rand -hex 32); INT=$(openssl rand -hex 16); DBP=$(openssl rand -hex 16)
printf 'JWT_SECRET=%s\nINTERNAL_TOKEN=%s\nDB_PASSWORD=%s\nCORS_ORIGINS=*\nRATE_LIMIT=120/minute\n' "$JWT" "$INT" "$DBP" > .env

# 无域名时：Caddy 用 IP 纯 HTTP 模式（有域名请看第七章）
sed -i 's/^pmc\.example\.com {/:80 {/' Caddyfile

# 启动（务必用 -f 显式指定生产文件！）
docker compose -f docker-compose.prod.yml up -d

# 查看状态
docker compose -f docker-compose.prod.yml ps
```

**验证**：
```bash
# 页面
curl -s -o /dev/null -w '%{http_code}\n' -A "Mozilla/5.0" http://localhost/     # 期望 200
# 登录接口（返回 token 即全链路通）
curl -s -X POST http://localhost/api/auth/login -H "Content-Type: application/json" -d '{"username":"admin","password":"admin123"}'
```

```bash

cd /opt/pmc-manager/deploy
```

## 七、域名 HTTPS 配置（已上线完成 ✅）

> 本系统已配置 pcm-personal.com + www 自动 HTTPS，以下为操作记录（未来换域名可复用）。

1. 买域名（腾讯云 DNSPod / 阿里云万网，`.com` 约 50-80 元/年）
2. 解析：域名管理 → 添加 A 记录，指向 `139.199.12.160`
3. 服务器上改 Caddyfile：
   ```bash
   cd /opt/pmc-manager/deploy
   # 把第 1 行的 :80 {  改回  你的域名.com {
   sed -i 's/^:80 {/你的域名.com {/' Caddyfile
   docker compose -f docker-compose.prod.yml restart caddy
   ```
4. Caddy 自动申请免费 HTTPS 证书，访问变为 `https://你的域名.com`

## 八、常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 端口 22/80/443 连不上 | 控制台防火墙没放行 | 见第三章第 2 步 |
| 拉镜像超时/失败 | Docker Hub 被墙 | 见第三章第 4 步加速器配置 |
| ghcr.io 镜像 unauthorized | GitHub Packages 默认私有 | 本地构建（第三章第 6 步）或用 PAT 登录 |
| 登录报"下游服务不可用" | 生产 compose 缺 command | 确保用修复后的 docker-compose.prod.yml（含 5 条 command） |
| curl 访问返回 403 | 反爬机制拦截了 curl UA | 用浏览器访问即可，属正常防护 |
